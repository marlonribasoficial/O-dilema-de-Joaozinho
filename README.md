# O Dilema de Joãozinho
Esse é meu primeiro projeto desenvolvido durante o primeiro challenge do Apple Developer Academy.

## 🚀 Sobre o Projeto
"**O Dilema de Joãozinho**" se trata de uma história interativa feita para o terminal.
A ideia central era criar uma experiência interativa onde o usuário precisa ajudar o personagem Joãozinho a tomar decisões importantes, explorando as consequências de cada escolha.

## 🛠️ Tecnologias Utilizadas e Aprendidas

- **Swift**: meu primeiro contato com a linguagem de programação da Apple.

- **Xcode**: também meu primeiro contato com o ambiente de desenvolvimento integrado (IDE) da Apple.
